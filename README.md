# أكاديمية زيغان

سورس موقع أكاديمية زيغان لكرة القدم، مبني بـ Astro وTypeScript، بتصميم عربي من اليمين لليسار.

## التشغيل المحلي

استخدم Node.js 24.21.0.

```sh
npm ci
npm run dev
```

افتح http://127.0.0.1:4321/. لفحص السورس وبناء الصفحات الثابتة شغّل `npm run check` و`npm run build`.

## محتوى النسخة العامة

تضم النسخة سورس الصفحات الخمس وبيانات الموقع وأصول التصميم المتاحة. استُبعدت صور اللاعبين المخصصة للمعاينة، وملفات خط Swissra، وأدلة التسليم والاختبارات المحلية التي تعتمد عليها. تعرض الصفحة حالة فارغة للصور وتستخدم الخط البديل المعرّف في التصميم. وضع المعاينة المحلي يظل مفعّلًا.
